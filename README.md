# 历史地图配准审定台

`map-registration-gate` 是面向历史地图数字化员与空间数据质量复核员的地理配准质量工作台。它把草稿基线修订与冻结确认、控制点批量预检导入、六参数仿射求解、残差整改、独立抽样复核和不可变发布清单串成一条带版本前置条件、持久幂等响应与摘要链审计的流程。

服务直接提供原生 HTML、CSS 和 JavaScript 页面，不需要 Node 构建链，也不连接外部地图服务。运行数据默认写入 `data/registration.json`。

## 构建

```bash
go build ./...
```

## 运行

```bash
go run ./cmd/server -addr=127.0.0.1:19081
```

浏览器打开 `http://127.0.0.1:19081`。监听地址仅允许回环地址；未传入 `-addr` 时默认使用 `127.0.0.1:19081`。也可以设置 `PORT` 为端口号，此时服务绑定 `127.0.0.1:<PORT>`。可用 `-data` 指定本地持久化文件。

## 测试

运行全部回归测试：

```bash
go test ./...
```

运行真实回环 HTTP 自检：

```bash
go run ./cmd/server -selftest -addr=127.0.0.1:19081
```

自检使用临时数据目录，依次完成建档、基线冻结、首次超限求解、问题点替换、重新求解、独立复核、发布冻结和清单摘要复算，然后主动关闭服务并清理临时数据。

## 业务约束

- 草稿基线可在版本保护下修订并核对规范化确认视图；冻结后不可修改，已发布任务为只读终态。
- 控制点支持逐条维护和批量预检导入。预检逐行返回边界、身份、标识和重复像素错误，任一错误都会阻止整批写入。
- 详情页给出有效/停用数量、四象限缺口、边界点、聚集点和仿射退化风险；阻断性诊断未消除时服务端拒绝求解。
- 每轮仿射求解都追加六参数、逐点残差、RMSE、最大残差和点集摘要，并提供相邻轮次质量对比；点位变化只失效当前引用，不删除历史证据。
- 超限点形成开放整改事项。替换前可预演覆盖和质量影响，正式替换必须携带同版本预演摘要、原因和证据，复算通过后才关闭事项。
- 复核员必须与数字化员不同，逐个稳定样本记录结论；退回项必须选择问题类型并填写说明，系统生成可追踪整改指令。
- 发布清单包含基线、控制点集、当前求解、结构化复核与审计链摘要，可重复生成不修改数据的分项验真报告。

所有写请求都携带 `expected_revision` 以拒绝陈旧页面覆盖，并使用 `request_id` 保存幂等响应。同一 `request_id` 携带不同负载会被拒绝。
